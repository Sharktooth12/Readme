## 👋 About
I build practical tools that fix everyday annoyances, from Android
apps to self-hosted servers. My work centers on three ideas:
**own it, fix it, see it.** That means no lock-in, repairable
hardware, and progress published in the open.

## 🔐 JRC Vault
**Research & development for privacy and data ownership.**

JRC Vault is my small hardware and software R&D shop. The idea is
simple: **own it, fix it, see it.**

### Current project: Pi-Vault
A self-hosted private file server built on a **Raspberry Pi 4**,
with shared storage and personal drives.
- **Private:** files stay on your server, not a third-party cloud
- **Repairable:** open hardware and sourceable parts
- **Flexible storage:** USB drive, SATA SSD, or NVMe options
- **No subscription:** no account to lose, nothing to shut down
- **Status:** v1.0 prototype in development

🌐 [jrcvault.duckdns.org](https://jrcvault.duckdns.org)
